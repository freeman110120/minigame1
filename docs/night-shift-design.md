# 夜班吊装

抖音竖屏 Unity 小游戏。玩家在夜间工地逐层吊装，跟随塔顶从城市升入风雨云，穿到明亮的云海，最终抵达近地太空。玩家每次抬高塔顶，都能看到同一空间里的景物随镜头升高而改变距离和遮挡关系。

美术使用自制写实建筑材质，城市以冷灰蓝为底，用暖工灯和窗灯突出可操作楼层。Unity 2022.3 静态样片已验证构图，真机表现待测。

## 核心循环

1. 预制楼层由滑车带动往返，并有小幅纵横摆动。摆动改变实际落点，随着楼层提高逐步增强。玩家用一次单指操作释放一层，释放到落稳期间锁定输入。
2. 释放时锁定画面上已有的水平位置，楼板以完整尺寸落下。上下楼层的相交区域是支撑面，接触面积至少为上层面积的 30%，重心需在支撑区域边缘内侧留出 0.08 米。休闲模式只检查新楼板与塔顶的接缝，投影线为青色时落板即可落稳。标准模式还检查下方各接缝及其上所有楼层的面积加权重心投影。
3. 两轴偏移均在 0.16 米内且通过当前模式的稳定检查时，楼板吸附到上一层中心并点亮窗灯。每落稳一层加一分。两种模式分别保存最高分，结算后可以重玩或切换模式。

标准模式在接缝接近失稳时标出对应楼层，并显示支撑安全区和重心投影。下方接缝失稳后，镜头先对准该接缝，上方楼段再绕支撑边缘倾倒。结算区分完全错开、接触不足和重心越界。

## 镜头与环境

采用固定斜俯视透视镜头，保持朝向和相对塔顶的构图。楼层落稳后，镜头才平滑抬升。塔顶和移动楼层始终留在竖屏可操作区域，工灯、边缘亮度和天气强度优先保证重叠边界可读。

街区、云带和浮岛都放在三维世界坐标中，通过透视和遮挡表现距离。极远的天空可以使用天空盒。高度是玩法尺度，使用可调的世界高度与过渡带。示意中的楼层阈值仅用于演示，正式参数在实机试玩中确定。

| 高度带 | 场景与交接 |
| --- | --- |
| 城市 | 暖工灯照亮塔顶，冷灰蓝街区在塔下逐渐缩小。接近云底时先抬高远景雾量、压低远景对比度，地面逐步被低云遮住。 |
| 风雨云 | 镜头进入有厚度的云带。雾、雨和冷光逐渐增强，塔顶近景保留清晰轮廓。接近云顶时先减弱雨，再降低近景雾量，让上方亮光逐渐显现。 |
| 天堂云海 | 镜头越过云顶后，刚穿过的云带留在脚下。光线逐渐转亮，浮岛按世界距离产生视差。继续升高时，云海退向下方，天空逐步变深。 |
| 近地太空 | 下方云海淡入大气边缘，近景云雾和天气退场，极远天空逐渐露出星空。塔顶保持可读的受光轮廓。 |

## 职责与数据流

| 职责 | 输入与输出 |
| --- | --- |
| 叠楼与局内状态 | 接收释放输入，计算各接缝的支撑面和重心，完成落稳或失败。发布落稳后的塔顶世界位置与当前分数，结算界面读取分数和本机最高分。 |
| 镜头跟随 | 只在落稳后更新跟随目标，平滑抬升，并输出实际镜头高度。释放与落下阶段维持当前镜头。 |
| 高度与氛围 | 读取实际镜头高度，根据配置计算相邻高度带的混合权重，在过渡区连续调整雾、光和天气。首轮只需要每带一份配置。 |
| 环境资源 | 接近过渡带前异步预备下一带，交接期间保留相邻两带，上一带退出可见范围后回收资源。加载完成时核对所属局次，等待期间继续显示已就绪的环境。按距离使用 LOD 和裁剪，复用楼层与天气粒子，控制透明云的屏幕覆盖率。 |

## 开发顺序与首轮验收

1. **先跑通城市玩法。** 验证适度偏移、完美对齐、完全错开、接触不足和多层累积偏心。确认窗灯反馈与计分正确，镜头在落稳后抬升，重来回到初始塔顶并保留最高分。
2. **做通城市、入云、出云。** 用一段短测试路线跨过云底和云顶。验证城市连续退到下方，风雨逐步增强再消退，出云后刚穿过的云带仍在画面下方。画面在交接处连续，前景判定边界始终清晰。随后用同一套配置扩展近地太空。
3. **在手机上验证边界和性能。** 连续跨带并在交接中重开，确认上一局的异步加载结果不会覆盖新局。分别在楼层下落和穿云时切后台再返回，确认不会误释放、重复计分或重复触发过渡，镜头与局内状态一致。重复重开并记录帧时间和内存变化，重点观察穿云峰值和上一带的资源是否按预期回收。
